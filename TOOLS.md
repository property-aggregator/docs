# Narzędzia programistyczne

Poniższe narzędzia to **rekomendacje**, a nie wymóg. Możesz pracować w innym edytorze, ale korzystanie z tych samych narzędzi ułatwia wzajemną pomoc w zespole.

## Edytory kodu (IDE)

| Repozytorium | Technologia | Rekomendowane IDE |
|---|---|---|
| backend | C# / .NET | JetBrains Rider |
| scraper | Python | JetBrains PyCharm |
| frontend | JavaScript / TypeScript | JetBrains WebStorm |

## Przydatne wtyczki

- **Database Navigator**: bezpośrednie połączenie z bazą danych, podgląd i edycja danych z poziomu IDE.
- **GitHub Copilot**: generowanie wiadomości commitów.
- **Claude Code with GUI**: pisanie kodu z pomocą Claude oraz praca z serwerami MCP. Konfiguracja MCP: [MCP.md](MCP.md).

## Uwagi

- Dokumentacja jest w publicznym repozytorium. Nie zapisuj w niej haseł, connection stringów ani kluczy API.
